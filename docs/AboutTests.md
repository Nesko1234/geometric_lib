# Отчет о тестировании юнит-тестов для геометрических фигур

## 1. Цели и задачи тестирования

### Цели:
- Проверка корректности работы функций вычисления площади и периметра для различных геометрических фигур.
- Обеспечение покрытия кода тестами с максимальным уровнем покрытия, включая положительные и отрицательные тесты.
- Убедиться, что функции правильно обрабатывают как корректные, так и некорректные входные данные.

### Задачи:
- Разработать и выполнить юнит-тесты для функций, вычисляющих площадь и периметр для круга, прямоугольника, квадрата и треугольника.
- Тестирование функции с положительными и отрицательными значениями входных параметров.
- Проверка поведения функций при вводе некорректных данных (например, строк, отрицательных значений).
- Оценка покрытия тестами с целью достижения 99% покрытия.

## 2. Описание тестируемого продукта

Тестируемые функции — это математические вычисления, определяющие площадь и периметр для следующих геометрических фигур:
- Круг: функции для вычисления площади и периметра.
- Прямоугольник: функции для вычисления площади и периметра.
- Квадрат: функции для вычисления площади и периметра.
- Треугольник: функции для вычисления площади и периметра.

### Требования к функциональности:
- Функции должны корректно обрабатывать различные размеры фигур, включая большие значения (например, миллион).
- Функции должны возвращать корректные результаты для граничных случаев (например, радиус или длина стороны, равные нулю).
- Функции должны быть защищены от некорректных входных данных и возвращать 0 для некорректных значений (например, отрицательных значений или строк).

## 3. Область тестирования

Тестирование охватывает следующие аспекты:

1. Функции для круга:
   - Площадь: area(r) (где r — радиус).
   - Периметр: perimeter(r) (где r — радиус).

2. Функции для прямоугольника:
   - Площадь: area(a, b) (где a и b — стороны прямоугольника).
   - Периметр: perimeter(a, b) (где a и b — стороны прямоугольника).

3. Функции для квадрата:
   - Площадь: area(a) (где a — длина стороны квадрата).
   - Периметр: perimeter(a) (где a — длина стороны квадрата).

4. Функции для треугольника:
   - Площадь: area(a, h) (где a — основание, h — высота).
   - Периметр: perimeter(a, b, c) (где a, b, c — длины сторон треугольника).

## 4. Стратегия тестирования

### Подход к тестированию:
1. Функциональные тесты:
   - Проверка корректности вычислений площади и периметра для разных значений входных данных.
   - Включение граничных значений (например, ноль, очень большие значения).
   
2. Тесты с некорректными данными:
   - Тестирование на отрицательные значения и строки, ожидая, что в таких случаях функция вернет 0.
   
3. Тесты с крайними значениями:
   - Проверка поведения функций при экстремальных значениях, таких как ноль и очень большие числа (например, 1 миллион).

### Используемые методы:
- Юнит-тестирование с помощью библиотеки unittest.
- Использование методов утверждения (assertEqual) для проверки результатов.

## 5. Критерии приемки

Тестирование считается успешным, если выполнены следующие условия:
- Все тесты для положительных значений проходят успешно.
- Все тесты для отрицательных значений (и некорректных входных данных) возвращают 0.
- Все функции корректно обрабатывают граничные случаи и экстремальные значения.
- Покрытие кода тестами составляет не менее 99%.

## 6. Ожидаемые результаты

Результаты тестирования должны включать:
1. Отчеты о тестах: для каждой функции проверяются как корректные результаты (для положительных значений), так и обработки ошибок (для отрицательных значений и некорректных данных).
2. Метрики качества: все функции должны иметь покрытие не менее 99%, а все ошибки и сбои должны быть правильно зафиксированы и исправлены.
3. Тестирование на ошибки: тесты должны выявить ошибки при неверных входных данных, таких как отрицательные числа и строки.
